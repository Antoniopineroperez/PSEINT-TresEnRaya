# PSEINT-TresEnRaya
Clasico juego de tres en raya creado con pseudocodigo

# Reglas:
El primer jugador en colocar 3 fichas de su tipo en diagonal, vertical u horizontal, gana.

# Instrucciones:
El tablero de la interfaz se muestra asi
<img width="93" height="63" alt="a" src="https://github.com/user-attachments/assets/4c7b18ca-315f-4c8f-8662-a4e2bbaa5196" />

Cada jugador tiene una letra, la letra representa tu ficha, por ejemplo estas
<img width="73" height="71" alt="b" src="https://github.com/user-attachments/assets/b817dff4-94d6-4387-832c-9587822520c9" />
<img width="79" height="63" alt="c" src="https://github.com/user-attachments/assets/4aa71bfa-5427-4ded-be2d-0b8509e4f1ea" />

El ordenador colocará aleatoriamente su ficha, tu objetivo es impedirle el paso y ganar.
Es un juego por turnos, el cual el script lo irá mostrando por pantalla, asi que hay espacio para la estrategia.
El juego te mostrará el número de turnos que ha durado la partida.
